
# ESX Company Announce
<img width="926" height="482" alt="Screenshot 2025-12-15 234509" src="https://github.com/user-attachments/assets/786cb263-13f7-42bc-85fd-b6e86e1f86a0" />

Simple ESX script that allows company employees to send in-game announcements using a clean UI.

## Features
- **/ann [message]** command
- Only available for company employees
- Clean and modern UI display
- Message shown at the top center of the screen
- Anti-spam system: **1 announcement every 30 minutes per company**

## Usage
```

/ann We are open!

```

## Dependencies
- ESX

## Installation
1. Drop the script into your `resources` folder
2. Add the resource to your `server.cfg`
3. Restart the server
